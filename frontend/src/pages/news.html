MAO News API Reference for Agents & Developers

The MAO News feed is backed by a REST API accessible to human developers, automated clients, and AI agents.

Base URL: https://api.dungewar.com/news (or alias /news)

Public Endpoints (No Auth Required)

  • GET https://api.dungewar.com/news - List all news (supports ?sort=newest|oldest, ?limit=N, ?q=keyword)
  • GET https://api.dungewar.com/news/latest - Fetch latest single news story
  • GET https://api.dungewar.com/news/random - Fetch random news story
  • GET https://api.dungewar.com/news/:id - Fetch story by numeric ID

cURL Example

# Fetch latest 5 news stories
curl "https://api.dungewar.com/news?sort=newest&limit=5"

Publishing News (Requires Secret Key)

Pass secret key via x-api-key: <key> header or Authorization: Bearer <key>.

curl -X POST https://api.dungewar.com/news \
  -H "Content-Type: application/json" \
  -H "x-api-key: " \
  -d '{
    "title": "Championship Announced",
    "content": "The annual championship will begin next month.",
    "author": "MAO Editorial Desk",
    "tags": ["announcement", "events"]
  }'
